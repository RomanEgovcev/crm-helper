## Возможности

### Перехват номера звонящего
- Перехватывает SIP INVITE через перехват WebSocket (в реальном времени)
- Отображает номер в поле ввода CRM с указанием направления:
  - 📥 Входящий (синий)
  - 📤 Исходящий (оранжевый)
- Определяет номер заявки из интерфейса CRM
- Номер остаётся на экране после завершения звонка
- Направление определяется по заголовку `call-type: incoming/outgoing`

### Контроль времени на линии (контроль очереди)
- Читает текущий таймер на странице CRM («Поиск заявки»)
- По достижении порога (по умолчанию 1 минута) выполняет действие:
  - **Перевойти в очередь** — автоматически кликает «Встать в очередь»
  - **Перелогиниться** — выходит и заново заходит в CRM, встаёт в очередь
- Автоматический перелогин с SPA-поддержкой (шаги сохраняются в `chrome.storage`)

### Таймер дозвона
- Читает время "Набор号码 (MM:SS)" из DOM CRM
- По достижении порога (по умолчанию 30 секунд):
  - Автоматически нажимает кнопку «Сбросить» для завершения звонка
  - Воспроизводит звуковой сигнал

### Контроль перерывов
- Таймер «Работа → Перерыв → Работа…» (по умолчанию 60/10 минут)
- Уведомления в Telegram при начале и окончании перерыва
- Индикатор на экране (правый нижний угол)
- Непрерывный звуковой сигнал по окончании перерыва с кнопкой «Выключить»
- Состояние сохраняется в localStorage — переживает перезагрузку страницы
- Использует `chrome.alarms` для работы в фоновых вкладках (Chrome не даёт `setInterval` в фоне)

### Отправка в Telegram (вручную)
- Кнопка 📨 рядом с номером для отправки по клику
- Формат сообщения:
  ```
  📞 +7 (904) 331-81-11
  📋 Заявка: №237243314
  🏢 Оператор: Теле2
  📍 Регион: г. Санкт-Петербург и Ленинградская область

  [💬 Telegram] [📱 Max]
  ```
- Inline-кнопки для перехода в Telegram / Max

### Определение оператора
- Автоматически определяет оператора и регион по номеру
- Использует num.voxlink.ru через background worker (CORS-free)
- Показывает факт переноса номера (MNP)

### Перелогин
- Автоматический перелогин с сохранением шагов в `chrome.storage.local`
- Работает в SPA (страница не перезагружается полностью)
- Retry-логика до 30 попыток для поиска кнопки «Встать в очередь»

### Блокировка beforeunload
- 3 уровня защиты от потери контекста при переходах между страницами

### Виджет Yandex Music
- Мини-плеер в правом нижнем углу CRM-страницы
- Кнопки: ⏮ предыдущая / ▶⏸ play-pause / ⏭ следующая / 🔈🔉 громкость
- Отображает текущий трек (исполнитель — название)
- Работает через MediaSession API + селекторы Sonata-дизайна Yandex Music
- Управление громкостью через range slider (+/-10% за клик)
- Перетаскивание виджета мышкой

### Поиск заявки по номеру
- Ввод номера заявки в popup → поиск в CRM API → отправка в Telegram
- Формат сообщения:
  ```
  📞 +7 (916) 770-00-18
  📋 Заявка: №238370694
  ℹ️ 1. Сафар, Московская область, 45 лет...
  🏢 Оператор: МТС
  📍 Регион: г. Москва и Московская область

  [💬 Telegram] [📱 Max]
  ```
- Запрос идёт через same-origin прокси на ect-russia.ru (`/v1/answers/id/{id}`)
- Токен авторизации извлекается из `sessionStorage` (Zustand store)
- Автоматическое определение оператора и региона через voxlink

## Установка

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/RomanEgovcev/crm-helper.git
   ```

2. Откройте Chrome → `chrome://extensions`

3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу

4. Нажмите **Загрузить распакованное расширение** (Load unpacked)

5. Выберите папку `crm-helper`

6. Расширение установлено! Нажмите на иконку в панели для настройки

## Настройка

Кликните по иконке расширения для открытия панели настроек:

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| Таймер на линии | Вкл/выкл контроль времени на линии | Вкл |
| Порог (мин) | Через сколько минут срабатывает | 1 |
| Действие | Что делать при срабатывании | Перевойти в очередь |
| Таймер дозвона | Вкл/выкл контроль дозвона | Вкл |
| Порог (сек) | Через сколько секунд без звонка | 30 |
| Тип звука | Сирена / Бип / Без звука | Сирена |
| Громкость | 0–100% | 80 |
| Перерыв | Вкл/выкл контроль перерывов | Вкл |
| Работа (мин) | Длительность работы | 60 |
| Отдых (мин) | Длительность перерыва | 10 |
| Bot Token | Токен Telegram-бота | — |
| Chat ID | ID чата Telegram | — |

**Важно:** Bot Token и Chat ID вводятся вручную в настройках расширения. Для Telegram Bot API может потребоваться VPN/прокси в Chrome.

## Техническая архитектура

```
crm-helper/
├── manifest.json        MV3, два content script (MAIN + ISOLATED), background worker, alarms, music script
├── content-main.js      MAIN world: перехват WebSocket (SIP INVITE/BYE) + beforeunload blocker + same-origin CRM API proxy + token extraction
├── content.js           ISOLATED: UI, таймеры, перелогин, Telegram, перерывы, звук, phone lookup, music widget, claim search
├── background.js        Service worker: Telegram send + phone lookup (CORS-free) + chrome.alarms + music tab routing
├── music.js             Content script для music.yandex.ru: play/pause/next/prev/volume через MediaSession + DOM
├── popup.html           Панель настроек + поиск заявки
├── popup.js             Загрузка/сохранение настроек + поиск заявки в CRM API
├── popup.css            Тёмная тема
└── README.md            Документация
```

### Как работает перехват SIP

1. `content-main.js` переопределяет `WebSocket` constructor в MAIN world
2. Перехватывает отправленные и полученные SIP-сообщения
3. Извлекает номер из INVITE:
   - Входящий: номер из заголовка `From:` (call-type: incoming)
   - Исходящий: номер из URI `INVITE sip:NUMBER@` с фолбэком на `From:`/`To:` если URI содержит WebSocket endpoint
4. Направление определяется по заголовку `call-type: incoming/outgoing`
5. Диспатчит `CustomEvent('crm-helper-caller')` с номером и направлением
6. `content.js` слушает событие и обновляет UI
7. Дебаунс 60 секунд предотвращает дублирование номера (Asterisk отправляет двойной INVITE)

### Почему background worker?

- Запросы к `num.voxlink.ru` идут через background service worker для обхода CORS
- `chrome.alarms` работает только в service worker (content scripts не имеют доступа к `chrome.alarms`)
